# Практическая часть лабораторной 3–4

Основной ноутбук — `main.ipynb`. Он проводит анализ KDD по задачам обоих проектов и включает обзор шести научных публикаций.

## Настройка окружения в Windows PowerShell

Из корневой папки проекта:

```powershell
python -m venv src\.venv
src\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r src\requirements.txt
jupyter lab src\main.ipynb
```

Исходные CSV и база SQLite находятся в `src/raw/dataset0304/`. В ноутбуке сохранены результаты выполнения: таблицы и графики.

## Содержимое

- постановка задачи и отбор таблиц;
- проверка качества данных и истории статусов;
- расчёт throughput, Cycle Time, WIP, CFD и диагностика закона Литтла;
- по 10 000 выборок длительности задачи для каждого проекта и оценки P50, P85, P95;
- сравнение оценок с длительностью задач из отложенной выборки.
